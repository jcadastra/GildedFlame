# Gilded-Flame
In Gilded Flame, players become a mysterious treasure hunter and explore an ancient castle. Illuminating their way with a torch, the treasure hunter solves puzzles, outwits monsters, and discovers treasure. 

Project Leads: Harvey Zhu, Eric Judys, Jin Chen

Contributors: Elli Belyarchik, Laila Dancy, Kedroy Laudat, Yuhan Sun, Judy Zhu

Programming Language: Java
